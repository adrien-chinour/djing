Barre sombre : valeur brute envoyée par le serveur. Barre claire : valeur lissée, celle que voient les scènes.

Calibrage : musique coupée, les dB bruts doivent rester sous le plancher ( dBFS) et toutes les barres à 0. Sinon, relancer le serveur avec un --min-ref plus haut (par exemple node server.js --min-ref -25). Si la musique ne remplit jamais les barres, baisser --range (par exemple 24). Chaque kick doit allumer la lampe.
