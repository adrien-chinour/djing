Barre sombre = valeur brute envoyée par le serveur, barre bleue = valeur lissée utilisée par les visuels.

Calibrage : musique coupée, les dB bruts doivent être sous le plancher ( dBFS) et toutes les barres à 0. Si ce n'est pas le cas, relancer le serveur avec un --min-ref plus haut (ex. node audio-server.js --min-ref -25). Si la musique ne remplit jamais les barres, baisser --range (ex. 24). Le kick doit faire clignoter la lampe onset à chaque coup.
